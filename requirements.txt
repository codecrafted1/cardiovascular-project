# ❤️ Cardiovascular Disease Prediction

## Features

- Predict cardiovascular disease risk
- Calculates probability score
- Modern Streamlit interface
- Gradient Boosting Classifier
- Exploratory Data Analysis (EDA)
- Model training pipeline

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Dataset

Cardiovascular Disease Dataset

Features include:

- Age
- Gender
- Height
- Weight
- Blood Pressure
- Cholesterol
- Glucose
- Smoking
- Alcohol
- Physical Activity

## Model

Gradient Boosting Classifier

## Performance

- Accuracy: ~72%
- Precision: ~74%
- Recall: ~68%
- F1 Score: ~71%

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
